Политика конфиденциальности приложения «График работы»

Дата вступления в силу: 23 октября 2026 г.

Настоящая политика описывает, какие данные обрабатывает мобильное приложение «График работы» (далее — Приложение) для Android, распространяемое через магазин RuStore.

Разработчик Приложения: Быков Владислав Николаевич, самозанятый (плательщик налога на профессиональный доход). Контакт для вопросов: vlades7@mail.ru.

1. Данные, которые вводит пользователь

Графики работы, типы смен, отпуска, больничные, отгулы, заметки к дням и настройки Приложения хранятся только на устройстве пользователя. Разработчик не получает к ним доступа: Приложение не имеет учётных записей, не использует собственные серверы и не передаёт эти данные третьим лицам.

Пользователь может удалить все данные, удалив Приложение или очистив его данные в настройках Android.

2. Доступ в интернет

Приложение обращается в интернет для:

  • загрузки производственного календаря РФ (переносы выходных, праздники) с открытых источников: репозитория xmlcalendar на GitHub (raw.githubusercontent.com) и сервиса isdayoff.ru. При этом передаётся только номер года, за который нужен календарь. Как и при любом обращении к сайту, этим сервисам становится известен IP-адрес устройства;
  • показа рекламы (см. раздел 3).

3. Реклама

В Приложении показывается рекламный баннер Рекламной сети Яндекса (Yandex Mobile Ads SDK, включая SDK аналитики AppMetrica). Для подбора и показа рекламы, подсчёта показов и защиты от мошенничества SDK может обрабатывать:

  • рекламный идентификатор устройства (Advertising ID);
  • технические данные: модель устройства, версию Android, язык, оператора связи, тип подключения к сети, IP-адрес;
  • сведения о взаимодействии с рекламой (показы, нажатия).

Эти данные обрабатывает ООО «ЯНДЕКС» в соответствии с его документами:

  • Политика конфиденциальности Яндекса: https://yandex.ru/legal/confidential/
  • Лицензионное соглашение Yandex Mobile Ads SDK: https://yandex.ru/legal/mobileads_sdk_agreement/
  • Лицензионное соглашение AppMetrica SDK: https://yandex.ru/legal/appmetrica_sdk_agreement/

Пользователь может сбросить или ограничить использование рекламного идентификатора в настройках Android (раздел «Конфиденциальность» → «Реклама»).

Данные, которые пользователь вводит в Приложение (графики, заметки и т. п.), в рекламный SDK не передаются.

4. Отключение рекламы по коду

Для отключения рекламы Приложение показывает случайный «код устройства». Он создаётся при установке, хранится только на устройстве и не связан с личностью пользователя. Пользователь сам решает, отправлять ли его разработчику.

6. Дети

Приложение не предназначено специально для детей и не собирает сознательно данные детей.

7. Изменения политики

Разработчик может обновлять эту политику. Новая редакция публикуется по той же ссылке с новой датой вступления в силу.
